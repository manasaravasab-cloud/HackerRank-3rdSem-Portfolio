## 📌 Activity Overview & Objectives

This repository contains optimal Python 3 solutions for the 5 mandatory HackerRank problems assigned as part of the 3rd-Semester CSE Studio Activity 8. Each problem has been implemented to maintain an optimal balance of Time and Space Complexity, passing 100% of hidden test cases.

### Key Learning Outcomes:
- Efficient manipulation of linear data structures, 2D matrices, dynamic arrays, and string formatting.
- Application of Hash Maps (`collections.Counter`) to reduce lookup complexities from $\mathcal{O}(N \times Q)$ to $\mathcal{O}(N + Q)$.
- Empirical and theoretical Big-$\mathcal{O}$ Time and Space Complexity analysis.
